# Онбординг-памятки ErfolgCRM

`onboarding.html` — одностраничные памятки для сотрудников по ролям
(**менеджер / инженер / директор** + раздел «Начало» для всех).

## Как открыть

Просто откройте `onboarding.html` двойным щелчком — страница работает офлайн,
без интернета и без установки (всё внутри одного файла).

Наверху — вкладки по ролям. На каждой памятке:

- **«Скачать всё в Word»** / **«Скачать эту памятку»** — сохраняет файл `.doc`,
  который открывается в Microsoft Word (можно распечатать и раздать).
- **«Печать»** — печатает все памятки сразу.

## Что внутри

Содержание собрано по реальным экранам системы (адреса вида `/tickets`,
подписи кнопок как в интерфейсе). Экраны, которые на демо-данных пока пустые,
помечены бейджем «на демо пусто» — они наполнятся после загрузки боевой базы.
Важные предупреждения выделены оранжевым (например, кнопка «Напомнить» шлёт
реальное письмо клиенту).

## Как править

Весь текст памяток лежит в самом файле, в блоке `<script>` — массивы `COMMON`
и `ROLES` (заголовок задачи, «где», шаги, заметка). Отредактируйте текст в этих
массивах и сохраните файл — страница и выгрузка в Word обновятся автоматически.
