# 152-ФЗ Compliance — ErfolgCRM v2

> Чек-лист обязательных действий для запуска SaaS-сервиса в РФ.
> Не юридический совет — финальная проверка с юристом обязательна.

## Роли по 152-ФЗ

- **Tenant (сервисный центр)** — оператор ПДн (обрабатывает данные своих клиентов).
- **Мы (ErfolgCRM SaaS)** — обработчик ПДн (обрабатываем по поручению tenant'а).
- Между нами и каждым tenant'ом — **DPA** (Data Processing Agreement, договор поручения).

## Чек-лист до первого платного клиента

- [ ] Уведомление в Роскомнадзор от ErfolgCRM (как обработчика).
- [ ] Уведомление в Роскомнадзор от каждого tenant'а (мы помогаем шаблоном).
- [ ] Политика обработки ПДн на сайте `app.erfolgcrm.ru/privacy`.
- [ ] Договор-оферта + DPA шаблон на сайте.
- [ ] Согласие субъекта ПДн фиксируется в `consent_records` (когда, IP, версия, цель).
- [ ] Хостинг — Yandex Cloud (аттестат УЗ-1 для ИСПДн).
- [ ] Шифрование ФИО/телефонов/адресов физлиц — pgcrypto + KMS (ключ per-tenant).
- [ ] AuditLog по всем изменениям (before/after, user, IP, ts).
- [ ] Шифрованные бэкапы с ротацией; раз в месяц — проверка восстановления.
- [ ] Подписан договор с DPO (Data Protection Officer).
- [ ] Внутренние документы: «Положение об обработке ПДн», «Перечень ИСПДн», «Модель угроз».

## Запреты в коде

- ❌ Отправка ФИО/телефонов клиентов в OpenAI / Anthropic / Google — нарушение 152-ФЗ + врачебной тайны.
- ❌ Логи с ПДн (см. redact в [logger.ts](../apps/api/src/lib/logger.ts)).
- ❌ Хранение ПДн вне РФ (S3-бакеты, БД, бэкапы — только Yandex Cloud).

## Разрешено

- ✅ Yandex GPT (по договору, данные в РФ).
- ✅ Локальная Ollama (данные не покидают периметр).
- ✅ Внешние LLM для запросов БЕЗ ПДн (агрегаты, описания работ без ФИО) — но ввести
  обязательный PII-прокси-слой, который автоматом замещает ФИО на токены.

## Хранение

| Данные | Срок |
|---|---|
| ПДн клиентов tenant'а | Пока действует подписка + 30 дней grace + по запросу tenant'а |
| AuditLog | 5 лет (152-ФЗ + бухучёт) |
| Бэкапы | Ежедневные 7 дней, еженедельные 4 недели, месячные 12 месяцев |
| Логи приложения | 90 дней |
