# Образцы документов

Сюда заказчик кладёт реальные образцы документов из своего сервисного центра.
Эти файлы НЕ коммитятся в git (см. `.gitignore`) — там могут быть ПДн клиентов.

Без этих образцов шаблоны PDF на этапе 3 я буду делать наугад. С образцами —
точно повторим формат, к которому привыкли клиенты.

## Что положить

| Папка           | Что                                         | Формат                |
| --------------- | ------------------------------------------- | --------------------- |
| `act_priema/`   | Приёмо-сдаточный акт (что приняли в ремонт) | PDF, DOCX, XLSX, фото |
| `schet/`        | Счёт на оплату (для юрлиц)                  | PDF, DOCX, XLSX       |
| `act_rabot/`    | Акт выполненных работ / сервисный отчёт     | PDF, DOCX             |
| `garantiya_to/` | Гарантийный талон, протокол ТО, журнал ТО   | PDF, DOCX, фото       |

## Анонимизация

Если в образцах есть реальные ФИО / телефоны клиентов — закрасьте или замените на «Иванов И. И.» / «+7 (900) 000-00-00». Если оставить как есть — это считается обработкой ПДн и потребует юридического оформления.
